🎬 録画に音が乗るか テスト

rectest ver.1
  1. マナーモード（サイレントスイッチ）は解除・音量を上げる
  2. 下の 「音を準備する」 を1回タップ
  3. コントロールセンターから 画面録画を開始
  4. A → B → C → D を順に1回ずつタップ（各タップで大きい文字が出ます）
  5. 録画を停止 → 写真アプリで再生
  6. 音が入っていた文字だけを教えてください（例：「BとDだけ鳴ってた」）
A〜Dは同じカキーン音を、4通りの違う出し方で鳴らします。どれが録画に乗るかで原因を確定させます。スピーカーからはA〜D全部鳴るはずです（鳴らないものがあればそれも教えてください）。
