# NICE SWING — 開発ドキュメント

スマホをゴルフクラブに見立てて素振り → センサーで検出 → 音＋みんゴル風演出。
「振ったらガチの打球音」で5秒動画のオチになる体感アプリ。
**佐伯くん × 籏崎さん の共同開発 / Presented by 夜レジ**

本番URL: **https://bombpass.github.io/swing/**

---

## 2モード
- **体感モード** `swing/index.html` … 手にスマホを持って素振り。DeviceMotion（加速度/ジャイロ）で検出 → 音・コース演出。単一ファイル（HTML+CSS+JS全部入り）。
- **カメラ分析モード（β）** `swing/camera.html` … スマホを置いて自分を撮影 → TF.js MoveNetで骨格をリアルタイム検出（Sportsbox型・体の動き分析の第一歩）。

**NICE SWING は `/swing/` 配下だけを触る。**

## ローカルで動かす
音源の `fetch` にサーバが要るのでローカルHTTPで：
```bash
cd bombpass.github.io && python3 -m http.server 8000
# → http://localhost:8000/swing/
```
⚠️ **DeviceMotion（センサー）とカメラは HTTPS 必須**。実機テストは本番URLで（ローカルは見た目確認のみ）。

## 技術の肝（★ここで沼らないで★）
今日、籏崎さんと丸1日かけて辿り着いた核心。**同じ轍を踏まないよう必読。**

- **判別の核＝「手が"空間で"速く動いたか」**。
  `DeviceMotionEvent.acceleration`（重力除去済みの直線加速度）を向き(alpha/beta/gamma)で world 座標へ回して積分し、**手の速さ(peakLin)** を出す。
- **ジャイロ（手首回転 ω）だけだと、座って手首スナップと本スイングを区別できない**。
  実測: 本スイングもスナップも **ω≈17で同じ**。だが **手の速さは 5.9 vs 1.3 m/s** で明確に差 → これで本物を判別。
- **ドリフト対策**: アドレス静止時にバイアス除去 ＋ 減衰付き積分(leaky)。
  積分した「移動距離(pathLen)」は長い動作でドリフト暴走する（座りで9.51m等）ので、**判定には距離でなく速さ(peakLin)を使う**。
- **左右の曲がり(スライス/フック)・フェース角0.1度・スピンは手持ちでは物理的に不可**（スマホは手に付いてる＝クラブヘッドでもボールでもない）。→ **演出として割り切る**。正確な分析が要るならカメラモード側（体の動き）。
- 主要パラメータは `index.html` 内の `const P={...}`（fullLin / minLin / leverK / distK2 等）。**実機の生データを見て実数で較正する運用**（画面下の「調整用」表示）。憶測でいじらない。
